# TradeBridge

TradeBridge is a B2B procurement and supplier platform for businesses, buyers and suppliers.

## Main Goal

Help businesses find trusted suppliers, post requirements, receive quotations, compare suppliers and manage procurement from one platform.

## Technology Stack

### Frontend
- React
- TypeScript

### Backend
- Java 17
- Spring Boot

### Planned Database
- PostgreSQL

## Future Features

- Buyer Registration
- Supplier Registration
- Supplier Profiles
- RFQ Management
- Quotation Submission
- Quotation Comparison
- Supplier Verification
- Purchase Orders
- Invoice Management
- Contract Management
- Delivery Tracking
- Vendor Ratings
- Procurement Analytics
- AI Quotation Comparison
